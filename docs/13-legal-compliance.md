# 13 · 合规与商业化风险

> 整理日期：2026-11-19。内容来自公开法规、官方答复和公开报道，用于团队内部判断方向，**不是法律意见**。收费功能上线前，需要按目标地区取得正式法律意见。来源列在文末。
>
> 本文是 [01 · 市场调研](01-market-research.md) 第 3 节"合规红线"的展开。

## 一句话结论

**目标是雀魂的营收模式，先从香港发布。** 照搬雀魂模式本身风险可控，前提是守住一条线：

> **花的钱只能变成角色和外观；牌桌上的筹码永远免费，不能买，不能换出去。**

一旦付费价值能流进牌桌，或牌桌上的输赢能流出成有价物，性质就变了。

德扑比麻将敏感，所以即使模式一样，有三处不能沿用雀魂的待遇：

- **分级更高**：澳洲同类德扑是 R18+，雀魂是 MA15+。
- **内地正式运营走不通**：版号路径不可预期，见第 5 节。
- **筹码设计更保守**：免费发放、免费重开，与付费完全分离。

## 1. 基线：雀魂模式各部分的风险

| 组成部分 | 风险 | 条件 |
|---|---|---|
| 免费对局、好友房免费 | 低 | 筹码每场免费发放，输光可免费重开 |
| 外观直购（皮肤、牌背、桌布） | 低 | 明码标价，只改显示，不附送筹码 |
| 好感度、角色养成 | 低 | 已购内容不因输牌扣除 |
| 段位、战绩 | 低 | 只用于展示和匹配，不兑换任何东西 |
| 月卡 | 低–中 | 写清领取、漏领、到期、自动续费规则 |
| 付费抽卡 | 中 | 按地区差异大。公示概率和保底；抽到的东西绑定账号。比利时应直接关闭，韩国需单独核对概率公示要求 |

## 2. 在此基础上加什么会出问题

**红线**：不做。**高**：做之前重审全部兑换路径。**中**：可做，但要配套措施。

| 加了什么 | 严重程度 | 后果 |
|---|---|---|
| 卖筹码，或输光后付费才能继续玩 | **红线** | 华盛顿州总检察长 2026 年 2 月起诉了 16 款社交赌场应用，其中包括 World Series of Poker，索赔超过 2.25 亿美元。这些应用的筹码同样不能提现 [1][2] |
| 礼包、月卡、抽卡里附送可下注筹码 | **红线** | 等同变相卖筹码，付费价值进了牌桌 |
| 筹码、道具可转赠或交易 | **红线** | 会催生币商回购，形成资金闭环。联众的德扑项目 2018 年因涉赌被公安部通报，涉案收入累计 3.35 亿元 [4] |
| 现金、实物、购物卡奖励；付费报名赛按名次发奖 | **红线** | 内地已有按德扑名次付现金被定为开设赌场的案例 |
| 平台抽成、代理、俱乐部分成 | **红线** | 抽水是认定开设赌场的典型特征 |
| 按底池大小或牌局胜负发抽卡券、购物券 | 高 | 输赢开始产出有价物，需要重审全部兑换路径 |
| 皮肤可交易、可上架市场 | 高 | 皮肤变成有价物；英国对可换现金或有价物的虚拟货币按赌注看待 |
| 付费角色带对局优势（看牌、加筹码） | 高 | 公平性问题，也让付费与输赢挂钩 |
| 集齐套装换大奖式的抽卡 | 中–高 | 日本 2012 年起禁止这种コンプガチャ，普通抽卡不受影响 [6] |
| 好友房开语音文字后放任私下结算 | 中 | 明知而不处理有帮助责任，免责声明不够。做法见第 3 节 |
| 面向内地做实机直播、投放、带下载链接招募 | 中 | 未获批网游的直播和引流有明确限制 |

## 3. 好友房开放语音和文字后，必须做到的三件事

风险点是**明知而放任**，不是没能检测到。平台不需要实时监听并终止对局，但下面三件事缺一不可。只有前两件而没有第三件，等于知道了却不管。

**① 提示：把规矩写明**

- 用户协议写明禁止现实财物结算
- 创建房间和进入房间时在界面内提示
- 文字聊天出现"转账""收款码""一个筹码多少钱"等词时弹出提醒

**② 举报入口：真实可用**

- 房间内有举报按钮，可选原因并附聊天记录
- 同时提供屏蔽和静音
- 举报后给出受理回执

**③ 处置和记录：有人管**

- 指定负责人，定期查看举报
- 分级处理：警告 → 关闭房间 → 封号，重点针对组织者和反复违规者
- 保存举报和处置记录，这是证明没有放任的依据

**配套要求：平台自身不提供结算便利。** 战绩统计可以做，但需要守住三点：

- 不做每筹码折算金额、货币单位，也不自动计算谁该付给谁多少
- 不加收款码、转账链接
- 措辞用"战绩""筹码变化"，不用"账单""盈亏结算"

依据：2026 年 6 月山东临邑一起 WePoker 俱乐部案的评析指出，该软件按牌局结果自动生成对账单，客观上便利了场外现金结算，是平台方的风险点 [7]。

## 4. 香港首发：要点和待办

香港没有内地那样的版号制度，游戏上架不需要出版审批，这是它适合首发的主要原因。需要对照的是《赌博条例》（第 148 章）：原则上赌博一律违法，除非属于法定豁免 [15]。

| 事项 | 风险 | 香港的情况和我们的做法 |
|---|---|---|
| 牌桌本身 | 低 | 条例对博彩的定义是：为赢得金钱或其他财产而玩博彩游戏 [13]。筹码免费、不可兑换、赢不到任何财产，就不落入这个定义。第 2 节的红线在香港同样是底线 |
| 按牌局结果发奖品 | 高 | 同一定义写明，不论玩家是否有输钱的风险都算 [13]。所以**免费参加不是挡箭牌**：免费赛事只要按名次发有价奖品，就可能构成博彩。奖励只给段位、称号和绑定外观 |
| 付费抽卡 | 中 | 香港没有专门的抽卡立法。政府 2021 年答复立法会时表示，虚拟抽奖视实际操作可能构成博彩，网上博彩同样受条例规管 [14]。做法：抽到的内容绑定账号，不可交易、不可兑换；公示概率和保底 |
| 宣传活动抽奖送实物 | 中 | 在香港办推广生意的竞赛需要申领牌照。首发期的宣传活动先不送实物或现金类奖品 |
| 监管动向 | 留意 | 政府 2026 年 5 月向立法会提出改进条例下的有奖娱乐游戏牌照制度，对象是夹公仔机、弹珠机等实体装置 [13]。不直接针对网络游戏，但说明带随机和奖品的玩法正在被收紧 |
| 商店分级 | 低 | 按商店问卷如实填写模拟赌博和随机付费内容，预期 17+ 或 18+ |
| 用户数据 | 低 | 昵称、设备、牌谱和聊天记录按《个人资料（私隐）条例》处理：告知用途、限定保存期限、提供删除途径，默认不录音 |
| 内地用户 | 中 | 香港首发不等于可以面向内地经营。不在内地做投放、直播和带下载链接的招募；是否在内地商店区上架，单独决定 |

**首发前需要香港律师书面确认的两件事：**

1. 按定稿的卡池、概率、保底和重复奖励规则，付费抽卡在香港是否可以开放。
2. 赛事和活动的奖励方案是否触及博彩定义，是否需要申领推广生意的竞赛牌照。

## 5. 内地：为什么能下载到德扑 App，仍然按走不通来规划

能在商店下载到，不等于获准运营。这里说的走不通，指的是**持版号正式运营**这条路。

**正式路径的现状**

- 内地游戏要收费必须有版号；能查到的德扑版号是 2017 年的历史记录。
- 2018 年监管收紧后，腾讯《天天德州》当年 9 月停服并清空数据 [3]。
- 没有证据显示新的德扑产品近年获批。

**那些仍能下载的 App**

- 检察机关在案件通报中把 WePoker 称为境外 App，称其为网络赌博平台 [8]。
- 在其上开俱乐部抽水的人持续被以开设赌场罪判刑，2026 年 6 月仍有新判决 [7]。
- 菠萝德州（PA Poker）由香港公司运营，走的不是版号路径，见下表。

### 菠萝德州（PA Poker）的公开信息

| 项目 | 内容 |
|---|---|
| 运营主体 | Hong Kong Metaverse Game Co., Limited（香港元宇宙游戏有限公司）[11] |
| 首次发布 | 2022 年 11 月（第三方商店数据） |
| 商店分类 | 娱乐类，不是游戏类 [11] |
| 年龄分级 | 17+，标注频繁或强烈的模拟赌博；部分地区为 18+ [11] |
| 收费 | 中国区有人民币内购，出售钻石和礼包，6 至 30 元 [11] |

没有查到它有内地版号的迹象，也没有查到针对它的案件或处罚。所以不能说它违法，只能说它走的不是版号路径。它卖钻石，钻石能换什么无法从商店页面判断；如果能换成牌桌筹码，那正是我们排除的做法。

### 被追究的是谁

| 角色 | 刑事风险 | 查到的情况 |
|---|---|---|
| 普通玩家 | 低 | 不兑现的娱乐不算赌博；参赌可能受治安处罚，查到的刑事案件被告都不是普通玩家 |
| 俱乐部主、局头、管理员、客服 | 最高 | 绝大多数判决针对这一层：招揽赌客、上下分、抽水，以开设赌场罪判刑 [7][8] |
| 代理、充值返款中介 | 高 | 渭南案的被告是为三个平台做客服和代理、替玩家充值返款的人，不是 App 的开发者 [9] |
| 开发和运营公司 | 有先例 | 境内持牌公司有被查的先例：联众 2018 年因德扑项目被公安部通报，高管被捕 [4]。没有查到 WePoker 开发方本身被定罪的公开案件。律师意见是平台明知有人利用其赌博、不制止还从中获利，就涉嫌开设赌场 [10] |

**对我们的含义：** 这些产品的存在说明执法有空档，不说明模式被允许。一个实名、可追溯、要正经收费的团队不能把计划建立在这种空档上。香港首发、内地不做的安排与此一致。
