# 08 · 演出设计（计划）

> 目标：每一个关键时刻都要"帅到想截图"，同时**绝不拖慢正常的对局节奏**。
> 人物立绘和表情包是后放进来的 PNG（见第 6 节），所有演出先用占位形象做好，素材到位后自动替换。
> 关联文档：[03 布局与演出](03-visual-layout-and-presentation.md)（旧版分级）· [06 心理战](06-mind-games.md) · [07 美术方向](07-art-direction.md)

## 0. 原则

1. **平时克制，关键时刻爆发。** 普通的下注、过牌、弃牌只用轻量动画。全下、对决、大牌、诈唬揭穿、翻盘、本局主役才用全套手法。越稀有的时刻越隆重。
2. **不拖节奏。** 有人等着做决定时，演出不超过约 1.5 秒；只有"已经不需要任何人做决定"的时刻（全下后发完公共牌、摊牌、结算）才允许更长的演出。
3. **永远可以跳过。** 点一下屏幕或按空格跳到结果。同一种大演出第一次完整播放，之后自动缩短。设置里可以选"完整、简略、关闭"。
4. **不泄露信息。** 演出只由已经公开的事件触发（下注、亮出来的牌、结算结果）。不会因为谁手里有大牌而提前出现任何异样。
5. **声音是一半的冲击力。** 每个关键时刻都配音效设计；先用程序合成的占位音效，以后换成正式素材。

## 1. 舞台

按 [07](07-art-direction.md) 的第一人称牌桌，场景分成这些层（从远到近）：

| 层 | 内容 | 用途 |
|---|---|---|
| 远景 | 赌场内景、虚化的人群和灯光 | 视差；镜头推近时虚化加重 |
| 中景 | 柱子、顶灯灯带 | 光线汇聚方向；高光时刻灯光闪动 |
| 角色层 | 5 个对手的立绘槽位 | 姿态和表情随事件切换；正在行动的人提亮、对焦 |
| 牌桌层 | 透视桌面、公共牌、底池、每人的下注 | 主要信息区 |
| 特效层 | 筹码粒子、光扫、冲击波、碎片 | 演出 |
| 前景层 | 你的手牌、深色的观众剪影 | 框景；镜头推近时前景虚化 |
| 后期 | 泛光、暗角、颗粒、调色、闪白、色散 | 整体质感和冲击帧 |
| 界面层 | HUD、操作区、心理战面板 | 永远清晰，不参与镜头运动 |

### 镜头词汇

| 镜头 | 做法 | 用在 |
|---|---|---|
| **推近** | 缩放到某个角色或桌心，边缘虚化 | 全下、慢开河牌、本局主役 |
| **甩镜** | 快速横移，带速度线 | 从一个人切到另一个人（对决开场） |
| **震动** | 短促、衰减的抖动 | 重注落桌、冲击帧 |
| **慢动作** | 演出时间放慢到 0.3 倍 | 河牌翻开前的一瞬间 |
| **冻结帧** | 定格 0.15 秒，同时闪白 | 逆转、四条以上大牌的第一拍 |
| **抽色** | 除焦点外全部变成黑白 | 逆转、抓诈 |
| **对焦转移** | 焦点从一个角色移到另一个角色，其余虚化 | 平时跟着行动的人走 |

## 2. 演出语汇（可复用的积木）

| 积木 | 说明 |
|---|---|
| **冲击帧** | 闪白 + 冲击波扭曲 + 色散 + 震动 + 低频重音，一起在 0.2 秒内完成 |
| **动态大字** | 印章式盖下（放大、旋转、落定、轻弹）；砸字（从镜头外飞入、撞击、碎屑）；书法字（笔画逐笔显出，配墨点飞溅）。用于 ALL IN、VS、牌型名、BLUFF、逆转、本局主役 |
| **卡牌光扫** | 翻牌时一道斜向高光扫过牌面；大牌时换成金色或彩虹色 |
| **筹码物理** | 筹码带旋转和翻面飞行，落桌时有弹跳和碰撞声；大额时像雪崩一样推进 |
| **粒子** | 金粉、彩带、玻璃碎片、火花、烟雾 |
| **心跳暗角** | 屏幕四周按心跳节奏收缩变暗 |
| **血条** | 对决时用格斗游戏风格的胜率条，每发一张牌都会扣减或回升 |
| **对焦虚化** | 景深模糊，突出焦点 |

## 3. 声音设计

| 类别 | 音效 |
|---|---|
| 日常 | 发牌"嗖"、翻牌"啪"、筹码清脆碰撞、筹码滑动、过牌敲桌两下、弃牌纸牌摩擦 |
| 紧张 | 心跳、上扬的嗡鸣、时钟滴答（最后 5 秒） |
| 冲击 | 低频重击、玻璃碎裂、金属锵声、人群惊呼和欢呼 |
| 荣耀 | 金币雨、铃声、号角短乐句 |
| 背景音乐 | 慵懒的爵士做底；有人全下时叠加紧张层；结算时换成胜利短乐 |

先用 WebAudio 程序合成占位音效（噪声、扫频、简单音调），以后同名替换成正式音频文件。

## 4. 时刻清单（分镜）

时长按"正常速度"计算。**级别**：S = 平时（不阻塞），A = 重要（短暂阻塞），S+ = 高光（只在无人需要决定时）。

### M1 发牌（S）
- 牌从荷官位（桌心远端）一张张飞出，带旋转，落到每人面前时轻弹一下。
- 你的两张牌最后飞到前景，**先背面朝上**。可以按住屏幕"眯牌"，牌角慢慢翻起看到花色点数，松手后完整翻开。不按的话 0.5 秒后自动翻开。

### M2 翻牌（S）
- 三张牌叠在一起滑出，扇形展开，再从左到右依次翻开，每张都有光扫。
- 公共牌和某人有关时（比如出现同花面），不做任何提示，避免泄露信息。

### M3 转牌、河牌（S，底池大时为 A）
- 普通：单张滑出、翻开，有光扫。
- 底池超过全桌筹码的 30%：翻开前多停 0.3 秒，暗角收紧一点，出一声心跳。

### M4 下注和重注（S）
- 筹码从角色面前滑到桌上。下注占底池越大，筹码堆越高、落桌越重：
  - 普通下注：清脆一声。
  - 超过底池：筹码"砸"在桌上，扬起一圈光尘，镜头轻震。
- 加注时角色立绘稍微前倾。

### M5 ALL IN（A，约 1.2 秒）
1. 0.0 秒：全屏变暗，速度线从全下的人那里向外放射。
2. 0.2 秒：斜向色带横扫过屏幕，带角色立绘和她的台词；"ALL IN"大字从镜头外砸进来。
3. 0.6 秒：筹码像雪崩一样推进桌心，镜头震动，低频重音。
4. 1.2 秒：色带撤出，她的名牌持续燃着一圈火光边框，直到这手结束。

### M6 对决 VS（S+，全下后有人跟、不再需要任何决定时）
1. **开场**（约 1.6 秒）：
   - 画面左右分屏，双方立绘从两侧冲进来，中间劈下一道闪电和"VS"大字。
   - 上方出现两条格斗游戏式的**胜率血条**。
   - 双方底牌同时翻开。
2. **三人以上全下**：变成"混战"版，三到四条血条叠放。
3. **每发一张公共牌**：血条按新的胜率扣减或回升，伴随打击音效。被反超的一方血条闪红。

### M7 慢开河牌（S+，只在对决中）
1. 镜头推近桌心，进入慢动作，心跳声加快，暗角随心跳收缩。
2. 河牌先背面朝上，再"眯牌"式地从一角慢慢掀开（约 1.5 秒）。
3. 翻开的一瞬间是冲击帧。
4. 如果结果被逆转，接 M13。

### M8 摊牌开牌（A）
1. "胜负揭晓"以印章形式盖在桌心。
2. 按亮牌顺序，聚光灯依次打到每个人身上，她的牌翻开（每人约 0.5 秒），牌型名用书法字写在牌下。
3. 全部亮完后，赢家的 5 张最佳组合牌浮起并发光，其他牌压暗。
4. 接着播放摊牌反应（已有）和派彩。

### M9 大牌（S+，按稀有度分档）
| 牌型 | 时长 | 演出 |
|---|---|---|
| 葫芦 | 约 1.0 秒 | 金色光扫，"葫芦"大字盖章，小规模金粉 |
| 四条 | 约 1.8 秒 | 冻结帧；四张同点数的牌从桌面飞到镜头前一字排开；"四条"书法字砸下，冲击波 |
| 同花顺 | 约 2.4 秒 | 五张牌在空中排成弧形，彩虹光扫依次掠过；"同花顺"书法字；烟花 |
| 皇家同花顺 | 约 4.0 秒，第一次必须完整播放 | 全场暗下，只剩一束顶光；五张牌一张一张从天而降，每张配一声铃；最后金色爆发、全屏彩带、人群欢呼；"ROYAL FLUSH · 皇家同花顺"双语大字 |
| **冤家牌**（双方都是大牌，例如三条对葫芦） | 加约 0.8 秒 | 两手牌在桌心正面相撞，迸出火花，"冤家牌！"大字，然后才分胜负 |

### M10 诈唬亮牌：BLUFF!（A，约 1.6 秒）
触发：别人都弃牌，赢家主动亮出一手弱牌（[06](06-mind-games.md) 的亮牌功能）。
1. 她的两张牌翻转着飞到桌心，面对镜头。
2. 紫色舞台光打下来，"BLUFF!"印章斜着盖在牌上，墨点飞溅。
3. 被骗弃牌的人：名牌上出现一道裂纹，"被骗了"小字弹出。AI 角色切换成生气或震惊。
4. 观众的笑声和"哦～"声。

### M11 抓诈和神跟注（A，约 1.6 秒）
触发：摊牌时，最后一条街的下注者亮出弱牌，并且输给了跟注者。
1. 抽色：除跟注者以外全部变成黑白。
2. 诈唬者的两张牌像玻璃一样碎裂，伴随碎裂声。
3. 跟注者那边：如果她自己也只是中等或弱牌，盖下"神跟注！"金色印章；否则盖"抓到了！"。
4. 颜色恢复，进入派彩。

### M12 逆转（S+，约 1.4 秒，接在 M7 之后）
触发：对决中，赢家在河牌前的胜率低于 25%。
1. 冻结帧，抽色，只有逆转者保持彩色。
2. "逆转！"砸字，冲击波，屏幕碎裂纹从中间扩散然后愈合。
3. 被逆转的一方立绘切换成震惊，名牌摇晃。

### M13 本局主役（S+，约 2.5 秒）
触发：赢下超过全桌筹码 25% 的底池（已有阈值）。按 [07](07-art-direction.md) 第 5 节：
1. 镜头推向赢家，背景灯光整排亮起。
2. 赢家换成全身胜利立绘，从座位上站起、张开双臂，身上出现"本局主役"绶带。
3. 筹码从桌面爆开飞起，再像雨一样落下。
4. 其他角色同时切换成反应表情。

和 M9、M11、M12 同时触发时，只保留最隆重的一个，其余合并成角标，避免连播疲劳。

### M14 淘汰（A，约 1.2 秒）
1. 名牌燃烧并化成灰飞走。
2. 立绘褪成灰色，盖上带名次数字的"OUT"印章（例如"OUT · 6"）。
3. 她面前剩余的东西被一阵风吹散。

### M15 时间压力（S）
- 剩最后 5 秒：心跳声，暗角发红并按心跳脉动，计时数字放大抖动。
- 进入时间银行：计时环变成金色，滴答声变快。

### M16 发现破绽（S，不阻塞）
- 角落弹出一张"破绽卡"，像收集卡牌一样翻转亮相：角色头像、破绽文字、闪光边框。
- 卡片自动飞进右上角的"笔记"按钮里。

### M17 终局结算（S+，约 6 秒）
1. 画面变暗，从第 6 名到第 1 名依次"翻牌"揭晓：每张名次卡从背面翻开，越往前越隆重。
2. 第 1 名：全身胜利立绘，金色光柱，彩带。
3. 段位分滚动累加，段位进度条推进；升段时有单独的"升段"演出（徽章碎裂、重铸成新徽章）。

## 5. 分级与节奏

| 级别 | 有人在等决定时 | 最长 | 频率 | 跳过 |
|---|---|---|---|---|
| S（平时） | 可以 | 0.6 秒 | 每手很多次 | 不需要 |
| A（重要） | 可以 | 1.6 秒 | 每局几次 | 点击跳过 |
| S+（高光） | **不可以**，只在无人需要决定时 | 2.5 秒（皇家同花顺 4 秒） | 每局 0 到 2 次 | 点击跳过；第二次起自动缩短 |

- **演出队列**：多个时刻同时触发时，按"最隆重的优先"合并，其余变成小角标。
- **"简略"模式**：S+ 缩短成约 1 秒的冲击帧加大字，去掉镜头运动。
- **"关闭"模式**：只保留 S 级。

## 6. 素材热插拔规范

所有图片按约定的路径放进 `web/public/art/`，游戏启动时读取清单；缺哪张就用占位形象顶上，**不需要改代码**。

```
web/public/art/
  characters/<角色ID>/
    idle.png  smug.png  nervous.png  angry.png      半身，1200×1600，透明背景
    shock.png  cry.png                               半身，同规格
    win.png                                          全身胜利，1600×2000，透明背景
    cutin.png                                        切入用半身，1200×1600（可选，缺省用 idle）
    stickers/smug.png ... thinking.png               表情包 512×512（8 张）
  backgrounds/
    table-far.png  table-mid.png  table-near.png     牌桌场景三层，3840×2160
    lobby.png                                        主页大厅
  cards/  back.png（可选牌背）
  manifest.json                                     列出已有的文件（构建时自动生成）
```

每个时刻会用到的角色姿态：

| 时刻 | 姿态 |
|---|---|
| 平时、思考 | idle（可能叠加 smug 或 nervous 表情） |
| ALL IN 切入 | cutin 或 idle |
| 对决 VS | cutin |
| 被逆转、被抓诈 | shock |
| 输掉摊牌 | cry 或 angry（按性格） |
| 本局主役、终局第 1 名 | win |

## 7. 技术实现

| 模块 | 内容 |
|---|---|
| `stage/` | 分层场景、第一人称牌桌、角色槽位（自动读 PNG，缺省用占位） |
| `fx/camera.ts` | 推近、甩镜、震动、慢动作、冻结帧、对焦转移 |
| `fx/timeline.ts` | 编排工具：并行、串行、等待、可跳过、受全局速度控制 |
| `fx/post.ts` | 泛光、暗角、颗粒、调色、闪白、色散、冲击波、抽色。基于 PixiJS 滤镜和 pixi-filters，可实时运行 |
| `fx/particles.ts` | 对象池化的粒子：筹码、金粉、彩带、碎片 |
| `fx/kinetic.ts` | 动态大字：盖章、砸字、书法 |
| `audio/sfx.ts` | 程序合成的占位音效；同名文件放进 `public/audio/` 后自动替换 |
| `fx/moments.ts` | 高光时刻（M5–M9、M13）和对决血条；由 `director.ts` 按引擎事件触发 |
| `ui/overlay.ts` | 主页（[07](07-art-direction.md) 第 6 节）和所有界面 |

**性能预算**：手机上保持 60 帧；粒子同屏不超过 300 个；后期滤镜分"高、中、低"三档，低档关闭泛光和色散。

**新增的判定**（客户端根据公开事件计算）：诈唬亮牌、抓诈、神跟注、逆转、冤家牌、大底池、多人全下。

## 8. 分阶段计划

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **A 舞台和地基** | 主页；第一人称牌桌；暖色界面；角色槽位和热插拔；镜头、编排、后期、粒子、动态大字、音效六个基础模块；M1 到 M4 | 主页能进对局；占位形象全部能被 PNG 替换；正常对局手感流畅 |
| **B 核心高光** | M5 ALL IN、M6 对决 VS、M7 慢开河牌、M8 摊牌开牌、M9 大牌四档和冤家牌、M13 本局主役 | 用固定牌序（`?seed=`）能逐个复现并录屏；全部可以跳过 |
| **C 心理战演出** | M10 BLUFF!、M11 抓诈和神跟注、M12 逆转、M14 淘汰、M15 时间压力、M16 破绽卡、M17 终局结算 | 同上 |
| **D 打磨** | 声音、演出合并规则、画质档位、手机性能、"简略"和"关闭"模式 | 中端手机 60 帧；一局快速赛在"完整"模式下不超过约 11 分钟 |

每个阶段结束都会更新试玩链接，附一段关键时刻的截图或录屏。

### 实现备注（A 到 D 已完成）

- **触发条件**
  - 冤家牌：摊牌时两手牌都是顺子以上、都用到了自己的底牌，并且至少一手是同花以上。
  - 大牌演出：赢家的最佳五张必须用到自己的底牌；整手牌都在公共牌上的大牌，不放演出。
  - 本局主役：一手赢下全桌筹码的 25% 以上。
  - 诈唬亮牌：别人都弃牌后，赢家主动亮出两张弱牌。"被骗了"的是她最后一次下注之后弃牌的人。
  - 抓诈和神跟注：河牌下注者（下注至少半个底池，或全下）亮出弱牌并输给跟注的人。跟注者自己是大牌时盖"抓到了！"，否则盖"神跟注！"。
  - 逆转：对决中的赢家，在河牌发出前胜率低于 25%。
  - 合并：同一手只放一个大演出，按皇家同花顺或同花顺、逆转、本局主役、四条、抓诈或神跟注、葫芦的顺序取最隆重的，其余写成角标。
- **时间压力**：只剩 5 秒时每秒一声心跳，屏幕边缘的红色暗角按心跳脉动，计时数字放大抖动；进入时间银行后计时变金色，滴答声变快。
- **破绽卡**：同一个破绽第 2 次被看到时，右侧翻出一张收集卡，3 秒后飞进"笔记"按钮。
- **终局结算**：名次卡从第 6 名翻到第 1 名，第 1 名在中间，有光柱和彩带；段位赛接着滚动段位分，升段时旧徽章碎掉、新徽章亮起。点击可以直接跳到结果。
- **对决**：全下后还有公共牌要发、两人以上亮牌时，播放 VS（三到四人时为"混战"），然后显示胜率血条。只在"完整"模式下慢开河牌。
- **跳过**：点击牌桌或按空格，当前演出剩下的部分立即播完。同一种演出从第二次起停顿缩短约 40%。皇家同花顺第一次不能跳过。
- **合并和节奏**：同一手里只有第一个全下放完整的 ALL IN 色带，之后的全下只在名牌上盖一个小章。一手里大演出累计超过约 6 秒后，后面的演出停顿减半。
- **音乐**：主页和牌桌各一段循环。有人全下时叠加紧张层（低音铺底和更密的镲），对决时拉满，分出胜负后退回。大演出播放时音乐自动压低。结算时前三名放胜利短乐句，其余放失落短乐句。音乐和音效可以分别开关，全部经过一个限幅器，叠加时不会爆音。
- **画质**：默认"自动"。手机从"中"开始，电脑从"高"开始；在牌桌上连续两个 4 秒窗口低于 42 帧就降一档，同一次游戏里不会再升回去，刚进牌桌的前几秒不计。三档的粒子上限分别是 420、220、110，渲染分辨率上限分别是 2 倍、1.5 倍、1 倍。
- **复现**：`?seed=N` 固定牌序；`?debug` 会把 `__poker.timing`、`__poker.moments`、`__poker.overlay`、`__poker.post` 挂到页面上，测试脚本可以快进到指定手数，也可以直接调用任意演出（例如 `__poker.moments.bigHand(2, 8, true, ['As','Ks','Qs','Js','Ts'])`）。
